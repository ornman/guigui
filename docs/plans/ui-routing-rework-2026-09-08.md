# 桂桂交互重构:错误路由统一 + 验证器 + 终态页重做(2026-09-08)

> 来源:2026-09-08 用户全边界盘点 + 四轮问答拍板(本文档只记录已拍板项,无待定项)。
> 涉及:前端 index.html 全视图、后端 api.py(diagnose 新增)、桥接契约 1.4.3 → 1.5.0、mock、状态画廊/矩阵同步。
> 当前基线:master `abfa460`,pytest 268 全绿。

## 0. 设计原则(所有改动的裁判标准)

1. **完成是全有或全无**:真验证通过 + 定时任务在岗,才配彩带;客观验不了的,不冒充成功,诚实叫「保存配置」。
2. **错误有唯一去处**:任何异常查第 1 节总表,不许页面自由发挥。
3. **断网统一落 v-guide**:任何视图发现不可达 → 跳排查页,不在原地挂小字。
4. **首装最少点击**:辅助确认框全删(换学号框已拍板删除),每步只留必要动作。
5. **验证器铁律**:只读检查可静默;有副作用的(真登/注销)必须用户看得见地跑。

## 1. 错误路由总表(第一章 = 最高优先级文档)

| 异常态 | 显示在哪 | 跳哪个页 | 按钮/动作 |
|---|---|---|---|
| 任何视图收到不可达(net:state unreachable / 开机 probe) | 跳 v-guide | v-guide | 挑网 / 等网 / 保存配置 |
| v-guide 期间网恢复 not_logged_in | 自动跳 v-login(现有) | v-login | 「立即登录」 |
| v-guide 期间他设备登好(logged_in) | 自动回主页 ok(现有) | v-main | — |
| 登录被拒(可达:密码/学号/绑定/限设备) | **留在表单页**,统一警告块 | 不跳 | 改对重试,试到过为止 |
| 节流 | 表单页中性 note(现有) | 不跳 | 等待后自动续 |
| 客观无法当场验证(不可达存的 / 06:50 锚前 / 在线但门户无注销配置降级存入) | 「保存配置」终态页(不撒彩带) | v-success(保存版) | 完成,回主页 |
| 任务计划被拦(首装提交时) | 被拦终态页:去掉「完成,回主页」 | v-success(拦截版) | 只有重建;重建成功且验证通过才放行彩带 |
| 任务计划被拦(日常发现:启动静默检测 / schedule:changed) | 主页横幅 | 不跳,就地重建 | 「自动登录还没生效,点此重建」点击=重建(带 busy);失败变「没建成,再试一次」 |
| 主页「再登一次」被拒(凭据问题) | 跳改密页 | v-login | 「立即登录」 |
| 主页「再登一次」不可达 | 跳排查页 | v-guide | 「去排查」 |
| 主页「再登一次」连续失败 ≥2 次 | 主页横幅 | v-diag(P1 上线前暂不显示) | 「试了几次还没登上?完整排查 →」 |
| 验证器(v-diag)结论:凭据问题 | 登录页 + 警告块预填结论 | v-login | 「立即登录」 |
| 验证器结论:任务被拦 | 拦截终态页 | v-success(拦截版) | 重建 |
| 验证器结论:一切正常 | 回主页 | v-main | — |
| 验证器结论:程序/系统问题 | 就地说明 | v-diag 结论区 | 「说给桂桂听 →」反馈 |
| 验证器也解决不了 | 反馈页 | v-feedback | 反馈终态页 |
| 反馈发出且收到 | 反馈成功页(工单号在文案行) | v-feedback 终态 | 「完成,回主页」 |
| 反馈没发出去(queued) | 反馈沮丧页(bot sad) | v-feedback 终态 | 次级「立刻重发」(回反馈页,草稿回填)+ 主按钮黑底白字「完成,等待自动补发」 |
| 密码还没验证过(仅保存配置路径) | 主页横幅 | v-login | 「去改一下」;连上后自动登成功即消 |

**主页横幅体系(终态,重做后仅三种)**:
①「密码还没验证过,去改一下」(仅保存配置路径) ②「自动登录还没生效,点此重建」(任务被拦) ③「试了几次还没登上?完整排查 →」(再登失败 ≥2,P1)。
**删除**:「今早没登上」横幅(最近结果行已显示;处理靠 out 态「再登一次」引导)。

## 2. 验证器(diagnose)设计 — P1

### 2.1 调用时机(已拍板)

| 时机 | 跑什么 | 用户看到 |
|---|---|---|
| 启动仪式期间 | probe(网络)+ taskStatus(任务),均只读秒回 | 无感;异常才亮横幅 |
| 主页「再登一次」失败 | login 本身即凭据验证,不重跑 | 失败计数,≥2 次出横幅 |
| 显式进 v-diag(横幅 / 设置页「立即体检」) | 全量五步含真登验证 | 分步链路可见 |
| 后台自动化 | 后端既有 login+selfheal | 失败才通知 |

启动静默**永远不跑全量**(第三步有副作用)。v-diag 进入即自动开跑,不需要再点开始。

### 2.2 后端 diagnose()(契约 §2.18,1.5.0)

顺序五步,逐步推事件 `diag:progress {step, key, state, detail}`,state ∈ running|ok|fail|skip:

| step | key | 做法 | detail 示例 |
|---|---|---|---|
| 1 | network | detect.probe 的网卡/SSID | 「已连上 Campus-WiFi」/「没连上网」 |
| 2 | server | HTTP 连 10.1.2.3 | 「10.1.2.3 可达」/「连不上」 |
| 3 | credential | 无凭据→fail「还没存密码」;not_logged_in→真登一次(副作用,如实验);logged_in→chkstatus 只读核对学号(不注销) | 「密码不对」/「在线,学号一致」 |
| 4 | task | is_task_current ×4(只读 schtasks /query) | 「4 项任务在岗」/「任务不在岗,多半被安全软件拦了」 |
| 5 | app | config 读回、vault 可用、crashlog 近期有无、bridge 活着(能调即活) | 「无崩溃记录」 |

返回信封 `{steps:[{key,label,state,detail}], verdict, exit}`,exit ∈ `login|task_blocked|ok|app_fault|net_down`。
**杀软拦截无法直接查**:只从任务缺失反推,detail 如实说「多半被拦」,不装确定。

### 2.3 v-diag 页(新视图,views 数组加入)

```
排查问题。
桂桂从头到尾查一遍,每步都给你看到:

① 网络连通      ● 正在查… / ✓ 已连上 Campus-WiFi
② 认证服务器    ✓ 10.1.2.3 可达
③ 凭据验证      ✗ 密码不对
④ 定时任务      ✓ 4 项都在岗
⑤ 程序自身      ✓ 无崩溃记录
──────────────────────
结论:<verdict 人话,大字>
[ <出口按钮,按 exit 变> ]
   排查也没解决?说给桂桂听 →   ← 固定小出口
```

出口路由:login→v-login(警告块预填结论)/ task_blocked→v-success 拦截版 / ok→goDaily / app_fault+net_down→就地说明+反馈出口。

### 2.4 入口(已拍板 F1/F3)

1. 主页再登失败计数 ≥2 → 横幅③「试了几次还没登上?完整排查 →」→ v-diag;
2. v-settings 系统区新行「立即体检」→ v-diag。

### 2.5 mock

`diagnose()` 实现;场景 `diag_ok / diag_cred / diag_task / diag_app`;与 `_setNet` 联动(当前网态影响第 1-3 步)。

## 3. 逐页改动清单

### 3.1 v-boot(P0)
- 日常开机(configured)probe 不可达 → **跳 v-guide**(不再落主页 down);从 v-guide 返回后主页 down 态保留(N3 拍板)。
- 仪式期间静默加 taskStatus(configured 时,并行,2s 超时保护)→ 不在岗 → 主页横幅②。

### 3.2 v-guide(P0)
- 标题左加 bot(cry/sad)+ .greet 布局,与其他页一致。
- 「10.1.2.3 · 不可达」状态条换 **B 方案:琥珀加强**(danger 样式 + ⚠ 图标 + 脉冲),与主页 down 态同族但更重。
- ②「重新检测」加等待反馈:点击进 busy,结果可见(它不是死功能:真调 probe,通了自动分流走)。
- ③ 文案改「先保存配置,连上后桂桂自动登录」方向;此路径进入的 v-login 提交按钮 =「保存配置」。
- reProbe 恢复 not_logged_in 时自动跳 v-login(现有,保持)。

### 3.3 v-ok / v-login 表单(P0)
- **警告组件统一为 B 基准**(密码框/表单下方暖色块):密码空、被拒全态(wrong_password / wrong_account / bound / limit_users)、验证器结论预填,同一个组件同一位置。
- **删除换学号确认框**:login-confirm DOM、uidChangeArmed/loginLandingUid 逻辑、相关文案;密码迁移静默执行,验证不过当场自纠。
- **停留时断网 → 直接跳 v-guide**(撤掉上一轮的「只刷状态行」;表单数据保留,回来还在)。
- 从 v-diag 进入 v-login 时:警告块预填诊断结论(P1)。
- 来源区分:普通路径按钮「立即登录」;v-guide ③ 路径按钮「保存配置」。

### 3.4 v-success 终态页(P0)
合法终态只剩三种(彩带页 / 保存配置页 / 拦截页),旧 verified=false 与 before_open 变体删除:
- **彩带页**:verified=true && task_ok(现 default 变体)。
- **保存配置页**(不撒彩带,bot idle 呼吸):不可达存的 → 「配置保存成功!连上校园网后自动执行登录」;锚前(06:50)→「配置已保存,校园网 06:50 开门后自动验证登录」;降级存入 →「配置已保存,明早第一次自动登录会真验证」。
- **拦截页**(重做):去「完成,回主页」按钮;只留「重建定时任务」;bot 表情 **sad(眯眼思考脸,不再 complete)**;文案「密码存好了,自动登录还差一步」。放行规则(路由,不是模糊文案):
  - rebuild ok && verified → 重渲为彩带页;
  - rebuild ok && !verified(保存配置路径)→ 保存配置页(附「任务已修好」);
  - rebuild fail → 留拦截页,按钮变「没建成,再试一次」。
- 反馈终态复用本页舞台(见 3.7)。

### 3.5 v-main 日常主页(P0)
状态收敛为四种,renderMain 按矩阵重写:

| 态 | 标题 | lede | 主按钮 |
|---|---|---|---|
| ok | 问候语 | 网的事交给我 | 立即重新登录 |
| out | 呜,刚才掉线了 | 登一下就回来 | **「再登一次」** |
| down | 现在连不上校园网 | 我陪你查查看 | 去排查(→v-guide) |
| off(总开关关) | 问候语 | 我先歇着 | (开关自己表达) |

- quickLogin 失败:AUTH_REJECTED → **openDetail('v-login')**(不再 lede 小字);NET_UNREACHABLE → v-guide(现有);INTERNAL → lede 兜底(保留)。
- 失败计数器 loginFailStreak:失败 +1,成功清零,≥2 → 横幅③(P1 随 v-diag 上线)。
- 横幅重做:删「今早没登上」;①② 落地(见第 1 节)。
- taskStatus/schedule:changed task_ok=false → 横幅②。

### 3.6 v-settings(P0/P1)
- 删除「定时任务被拦」行(归主页横幅②)。
- 系统区加「立即体检」行 → v-diag(P1)。

### 3.7 v-feedback(P0)
- 发送后必进终态页(复用 v-success 舞台,内容区换反馈文案):
  - **收到**:bot happy,标题「收到啦,谢谢你」,文案行含工单号(「凭据号 GG-37,报问题时说它」),按钮「完成,回主页」(按钮不带编号)。
  - **没发出去(queued)**:bot sad(沮丧),标题「暂时没发出去,已存本地」,按钮组:次级「立刻重发」(回 v-feedback,**草稿回填刚填的内容**)+ 主按钮黑底白字「完成,等待自动补发」。
- 草稿机制:sendFeedback 发出前快照表单内容;queued 终态的「立刻重发」回填;补发成功后清。
