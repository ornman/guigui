# ADR-0005:代码签名策略

- **状态**:**已批准·路线 d**(2026-09-12 用户拍板:开源发布 + 免费签名档)· 待实施(第一步 = 开源前置审计)
- **日期**:2026-09-11
- **关联**:审计 R4 / S2(全局放大器);2026-09-07 杀软三杠杆(放行/安装期建任务/签名)中唯一未落地的一支

## 背景

全链无签名:`build_guigui.bat` 无 signtool 步骤、`guigui.spec` 无签名相关配置、`setup.iss` 无 SignTool 段,仓库 grep `signtool|authenticode` 零命中。

签名是**唯一能同时压低 schtasks/powershell/netsh/tasklist 全部行为特征误报的杠杆**——ADR-0001/0002/0003 改的是「行为的形状」,签名改的是「行为的分母」。同样的 spawn schtasks,签名软件是「正常安装行为」,未签名软件是「可疑持久化」。签名不解决 100% 误报(行为引擎仍会记分),但决定多数杀软的默认裁决倾向。

## 选项与事实(呈报,不代拍)

| 选项 | 成本量级 | 实际收益 | 备注 |
|---|---|---|---|
| a) 维持现状 + 加白指引 | 0 | 长尾误报留存;依赖 ADR-0001/0002/0003 压形状 | task_blocked 自救指引已有 |
| b) 自签证书 | 0 | **仅完整性自证,不建立信任链,不降误报** | 不推荐,列此防止误选 |
| c) Azure Trusted Signing(Basic 档) | ~$10/月 量级 | 标准 OV 级降误报 | 需 Azure 账号 + 个人/组织验证;3 年内不可换供应商的条款需细读 |
| d) OV 代码签名证书 | ~百至千元/年 | 同 c;一次性年费,无月费 | 个人开发者可申请;ev 档(即时 SmartScreen 信誉)贵数倍,对定向分发小软件性价比存疑 |
| e) 开源发布后走免费档(SignPath.io / Certum OSS) | 0 | 同 c/d | **前提是把仓库公开**——与「桂航定向小软件、非通用工具」的定位冲突,需先拍定位 |

## 决策规则

用户拍预算/路径后回填状态;无论选哪档(除 a/b),实施均为同一套:

## 实施清单(拍板后执行)

1. `build_guigui.bat`:PyInstaller 产出后 `signtool sign /fd SHA256 /tr <TSA> ...(guigui.exe + onedir 内主 DLL)`;ISCC 段配置 `SignTool` 签安装器。
2. `安装说明.txt` / README:登记证书指纹与「验证签名」指引(用户侧自证渠道)。
3. 真机验证:右键 exe → 属性 → 数字签名可见;火绒/Defender 默认配置下安装+建任务一轮无拦截提示。

## 后果(拍板后回填)

- c/d/e:行为整改(0001/0002/0003)的收益被完整兑现;SmartScreen「未知发布者」蓝条消失(信誉积累需时间)。
- a:收益打折,但 0001/0002/0003 仍是净改善。

## 回填(2026-09-12):路线 d 拍板,实施链定稿

用户拍板 **d(开源发布 + 免费签名档)**。含义与执行顺序:

0. **开源前置审计**(第一步,2026-09-12 已启动):全仓扫描真实学号/密钥/个人信息/本机路径/历史泄漏,三档清单呈报;A 档清零(或用户明示接受)前不得公开。
1. **公开仓库**(用户动作):GitHub 建仓 + push——对外发布动作,必须用户亲自确认执行。
2. **签名申请**(用户动作):SignPath.io(免费 OSS 档)或 Certum Open Source 证书,均要求项目已公开;账号与申请由用户完成。
3. **构建链接入**(agent 纯执行):build_guigui.bat 加 signtool 步骤(exe + 安装器),密钥走环境变量/本地不入仓。
4. **指纹登记**:安装说明/README 登记证书指纹与验证方法。

边界说明:开源 ≠ 转型通用产品——SPEC §1「桂航定向、非通用工具」定位不变;公开的是代码与文档,不改变产品方向与决策基线。AGENTS.md 等含本机路径的文件是否随仓发布,依审计结论处理。

## 回填补记(2026-09-12 晚):签名档暂不申请,改走社区无签名方案

用户裁决:**不申请 SignPath/Certum**(原路线 d 的签名档搁置),采用开源社区主流分发方案:

1. **GitHub Releases 分发安装包**(正本渠道;官网/群聊只放链接);
2. **发布校验和**:每个 Release 附 SHA-256,用户可自证完整性;
3. **杀软误报申诉三件套**:向 Microsoft 安全智能门户、火绒、360 提交样本/误报申诉(零成本,按厂商逐一处理;行为面已由 ADR-0001~0003 压到最低,残余=SmartScreen「仍要运行」蓝框与长尾误报);
4. SignPath 免费档**保留为后续可选**(仓库已公开,申请门槛已具备,若误报申诉不胜其烦再启用)。
