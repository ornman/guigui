# ADR(架构决策记录)— 桂桂

## 约定

- **编号**:递增四位(`0001-`),不复用、不改号;标题 slug 用英文,正文中文。
- **状态**:`提议` → `已批准·待实施`(用户明确指令)→ `已接受`(实施+验证完成)/ `已否决`(附理由);`待拍板` = 呈报用户裁决中,**任何 agent 不得代拍**。
- **决策变更**:不改旧 ADR,新开 ADR 并在旧文头部加「被 ADR-00XX 取代」;重大取舍须记录替代方案与不选理由。
- **模板**:标题 / 状态 / 日期 / 关联 / 背景 / 决策(含可行性证据)/ 替代方案 / 后果 / 实施清单(零上下文可执行)/ 验证基准。
- **来源**:本批 ADR 源自 2026-09-11 后端架构审计([docs/tech/guigui-backend-audit-2026-09-11.md](../tech/guigui-backend-audit-2026-09-11.md)),审计风险登记册 R1-R8 与 ADR 一一映射。
