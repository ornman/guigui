# 提示词模板(三类)

> 治理文档之一。单人 + agent 协作的主力武器:**把已验证有效的提示词结构固化成模板,新会话/subagent 直接套**。三类覆盖本项目全部工作形态。模板里的 `<>` 是填空位。配套纪律见 `sdlc.md`。

## T1 · 新功能 / 新模块开发

**何时用**:从零做一个功能(新视图、新机制、新链路)。铁律:PRD 先行,先计划后动手。

```
你是桂桂项目(仓库 <repo路径>)的开发 agent。先读以下文件建立上下文:
1. docs/SPEC.md(项目总纲:架构基线/质量基线/决策基线)
2. docs/prd/<相关章节或全文>(产品语义)
3. docs/tech/guigui-bridge-api-v1.md(契约,若触达前后端接口)
4. docs/prd/guigui-state-matrix.md(若触达视图×状态)

需求:<一句话,用户原话>
边界:只做 <X>,不做 <Y>;触达决策基线(SPEC §4)的项停下来呈报。

产出顺序(不许跳步):
1. 先交「理解 + 方案」(含落点文件/函数、AC 列表、文案拟稿),等我点头;
2. 我点头后写 docs/plans/<主题>-<日期>.md(带执行约定节);
3. 执行 + 测试;pytest 从仓库根跑,基线 <N> 测只增不减;
4. 文案/交互改动附场景化拟稿清单等我过目,不直接上线。
```

**已验证来源**:v2 后端计划、反馈系统、业务重梳理(2026-09-06)均按此形态跑通;「先交方案等点头」一栏是 2026-09 设计方案先确认纪律的直接产物。

## T2 · 问题修复 / 审计排查

**何时用**:用户报 bug、UI 文字不对、行为异常、或主动审计找问题。铁律:先定位后动手,定位不到就问。

```
你是桂桂项目的排查 agent。仓库 <路径>。问题:
<用户原话描述 + 用户看到的画面/文字>

定位链(按顺序走完才许动手):
1. 静态:grep 前端 HTML/JS 与后端源码;
2. 动态:文案可能来自后端信封 message / mock / JS textContent 赋值点,
   先搜数据源再下结论——「静态搜不到 ≠ 不存在」;
3. 数据源:mock 场景表、后端拒绝文案表(drcom REJ_CODE 等)、配置默认值;
4. 仍找不到 → 停下列出我该确认的问题,不猜着改(改错位置=改两次)。

定位到后输出:确切节点(file:line)+ 根因一句话 + 修法选项(若有取舍列出,
无取舍直接修)+ 验证方式。纯技术修复直接做;设计/文案改动先呈报。
验收视角默认带:该问题关联的每个用户承诺,验证链一并过。
```

**已验证来源**:「自助服务平台链接」事故反推的定位链(2026-09-06);杀软审计按此形态展开(探查→核实→评分→ADR)。

## T3 · 零上下文接力执行(subagent 启动话术)

**何时用**:计划/ADR 已批准,把执行交给 subagent 或新会话。判据:能写出这份话术 = 纯执行项;写不出 = 回 S1/S2。

```
你是执行 agent,在 <OS/环境> 机器的仓库 <路径> 工作。今天是 <日期>。

必读(唯一权威执行依据,先读完再动手):
- <计划文档路径 或 ADR 路径列表>
- docs/SPEC.md §3 质量基线

执行顺序与范围:
1. <单元1:做什么,按文档哪节>
2. <单元2…>(顺序、门槛、每单元后的动作)

硬性纪律(违反即返工):
- 测试:python 用 <venv路径>;pytest 必须从仓库根跑;基线 <N> 测全绿(含新增)。
- 边界:绝不 <碰真实在岗数据/任务/凭据 等红线>;一次性探针用完即删。
- git:每单元 commit,只 add 自己改的文件;工作区他人的未跟踪/已改文件严禁 add。
- 拍板项:<列出禁止代拍的项> 严禁实施、严禁改状态。
- 不顺手修:与本任务无关的代码/文档瑕疵一律不碰,发现了写进收工报告。

收工报告必含:每单元结局 / 测试数字 / 真机验证结果 / commit 哈希列表 /
偏离任务书的决定及理由 / 环境跳过项(如实,不许造假)。
```

**已验证来源**:杀软整改批 subagent(2026-09-11)按此模板执行 4 个 ADR:145 次工具调用零偏航,主动守纪律跳过冲突项并如实报告——模板里的「偏离与理由」栏就是为这种时刻准备的。

## 使用守则

1. 模板是**下限不是上限**:任务越重,「必读」「纪律」越要写实;空泛的纪律等于没有。
2. 任何一次执行翻车,复盘后**回填模板**(教训进纪律栏),让下一次免费受益。
3. 三类之外的形态(如纯调研、竞品分析)不必硬套;但「定位链」「先方案后动手」「收工报告」三件骨架通用。
