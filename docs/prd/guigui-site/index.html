常见问题

用之前先问清楚的。

只适用于桂林航天工业学院吗?其它学校能用吗?
目前只针对桂林航天工业学院的 Dr.COM 校园网认证流程适配,暂不支持其它学校。 如果你也是 Dr.COM 院校(且认证页面结构一致),可以联系开发者评估适配。 本软件与学校官方无关,是桂航在校学生开发的辅助工具。
校园网认证密码存哪?安全吗?
密码走 Windows 凭据管理器(Credential Manager),不存明文、不写入配置文件。 v1 的旧版 config.json 明文存储方式已被新版废弃,升级时旧文件会被迁移并清空。
每天 7:00 会不会太晚/太早?能调吗?
默认 7:00 是基于"大多数桂航学子起床时间"定的经验值。 在「高级设置」里可以改成任意两位时间,带六个常用时间药丸一键填。 校园网认证服务器每天 06:50 开门,设置早于这个时间会被前置灰提醒。
Mac 也能用吗?
暂时不支持。桂桂是 Windows 桌面应用(customtkinter + PyInstaller),Mac 版本未排期。 如果你需要 Mac 版,可以在仓库提 Issue。
为什么不用托盘图标?
桂桂设计为"GUI 仅配置时出现"——平时不应该出现在屏幕角落。 关闭窗口后只留一枚胶囊浮标,感知面只有系统通知。开关全在一张卡里,不打扰。
WiFi 兜底是什么?
检测到你连上预设的几个校园 WiFi(如 GUAT-WiFi、桂航宿舍网等)时, 自动触发一次登录兜底。SSID 列表是「扫描点选」,免手填,避免选错连不上。
怎么升级 / 卸载?
升级:重新下载最新安装包覆盖安装即可,配置和日志都会保留。 卸载:走 Windows「设置 → 应用」卸载,会保留一份 config.json 备份在用户目录, 卸载 30 天后自动清理。
