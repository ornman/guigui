Fig. 03 FAQ · 7 项

用之前先问清楚。

七个最常被问到的问题。挑你关心的看。

Q1SCOPE 只适用于桂林航天工业学院吗?其它学校能用吗?
目前只针对桂林航天工业学院的 Dr.COM 校园网认证流程适配。如果你是同 Dr.COM 院校,可以联系开发者评估适配。本软件与学校官方无关,是桂航在校学生开发的辅助工具。
Q2SECURITY 校园网认证密码存哪?安全吗?
密码走 Windows 凭据管理器(Credential Manager),不存明文、不写入配置文件。旧版 config.json 明文存储方式已废弃,升级时会迁移并清空。
Q3TIMING 每天 7:00 会不会太晚或太早?能调吗?
默认 7:00 基于大多数桂航学子的起床时间。在高级设置里可以改成任意两位时间。校园网认证服务器每天 06:50 开门,设置早于这个时间会被前置灰提醒。
Q4PLATFORM Mac 也能用吗?
暂时不支持。桂桂是 Windows 桌面应用,Mac 版本未排期。
Q5UX 为什么不用托盘图标?
桂桂设计为 GUI 仅配置时出现。平时不打扰,感知面只有通知。
Q6FALLBACK WiFi 兜底是什么?
检测到你连上预设的几个校园 WiFi(如 GUAT-WiFi 等)时自动触发一次登录。SSID 列表是扫描点选,免手填。
Q7UPDATE 怎么升级或卸载?
升级:重新下载安装包覆盖,配置和日志保留。卸载:走 Windows 设置的应用卸载,会保留一份配置备份在用户目录,30 天后自动清理。
