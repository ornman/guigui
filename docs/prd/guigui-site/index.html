Methods
· 8 触发器

不靠一个触发器,靠一摞。

单一时间点会漏。多层叠加保底,总有一层替你兜住。

01 Trigger
起床心跳7:00 前后 30 分钟,每 5 分钟尝试一次,任一次成功即停。
02 Trigger
开机补登开机登录系统后 30 秒内补一次。周末也启用。
03 Trigger
白天巡逻联网中途被踢,30 分钟内自动重连。默认开启。
04 Fallback
WiFi 兜底连上预设的校园 WiFi 即触发登录。SSID 扫描点选,免手填。
05 Trigger
唤醒补登笔记本睡眠唤醒后 30 秒内补登,合盖再开自动接上。
06 Policy
假期静默连续 48 小时不可达,心跳降为每天 1 次且不通知。回校自动恢复。
07 UX
关窗即静关闭窗口无托盘图标,只留一枚胶囊浮标,点一下还原。
08 UX
系统通知成败都走 Win11 通知中心,失败 3 次内自动去重不刷屏。

FAQ
· 7 项

用之前,先问清楚。

七个最常被问到的问题,挑你关心的看。

Q1 Scope只适用于桂林航天工业学院吗?
是。桂桂只针对桂林航天工业学院的 Dr.COM 认证流程适配,其它学校暂不支持。同 Dr.COM 院校可联系开发者评估。本软件与学校官方无关,是桂航在校学生开发的辅助工具。
Q2 Security密码存哪?安全吗?
密码走 Windows 凭据管理器(Credential Manager),不存明文、不写入配置文件。v1 的 config.json 明文方式已废弃,升级时迁移并清空。
Q3 Timing7:00 太晚或太早?能调吗?
默认 7:00 基于多数桂航学子的起床时间,高级设置里可改成任意时间,带常用时间药丸一键填。认证服务器每天 06:50 开门,设早了会前置灰提醒。
Q4 PlatformMac 能用吗?
暂不支持。桂桂是 Windows 桌面应用,Mac 版未排期。
Q5 UX为什么没有托盘图标?
桂桂只在配置时出现,平时不打扰。关窗后只留一枚胶囊浮标,感知面只有系统通知。
Q6 FallbackWiFi 兜底是什么?
检测到你连上预设的校园 WiFi(如 GUAT-WiFi 等)时自动触发一次登录。SSID 列表扫描点选,免手填。
Q7 Update怎么升级或卸载?
升级:重新下载安装包覆盖,配置与日志保留。卸载:走 Windows 设置的应用卸载,用户目录留一份配置备份,30 天后自动清理。
