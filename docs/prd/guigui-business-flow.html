⏱ 验证阶梯时序(在线态)

① 注销当前会话提交上方如实一行:"会先注销当前登录,网络断几秒";线上是别的学号 → 注明"线上的是 6503…21,验证时会先注销它"
→
② 等状态翻转最多 6 × 0.5s 轮询;不翻转 → 降级:密码存"未验证",明早首试
→
③ 真登一次刚注销会被限流(waitsec)→ 等 4s 重试一次
↓ 五路结果(未登录态跳过①②,直接真登)
登录成功密码入库,标记已验证 → 庆祝页(唯一通往庆祝页的路)
密码不对userid error2旧密码接回网络 + 按钮恢复 + 内联"密码不对";首装无旧密码 → "网先断着,输对马上通"

绑定被拦bind userid error密码其实是对的 → 指引自助服务平台查绑定/换绑
网络中途够不着密码没被否认 → 存"未验证",明早首试真验证,失败弹通知

⏱ 06:50 开门前提交(锚点)

被拒不判"密码错误" → "还没到开门时间(06:50),密码先存着,明早自动验证"(存未验证)。门户维护页(格式不认识)→ 如实展示不猜测。

图 5 · 凭证可信度(贯穿全流程的单一真源)

两个值:已验证 / 未验证 · 一切横幅、失败通知、改密引导都由它和"当日失败"驱动

→ 已验证(置真) · 验证阶梯真登成功(首装/改密)
· 日常每拍真登成功(tries>0)
· 主面板「立即登录」用已存密码成功
↕
→ 未验证(置假) · 06:50 后服务器明确拒绝(密码不对 error2)
· 新密码在"网络够不着/降级"下入库(明早首试前)
│
→ 保持不变(不冤枉密码) · 06:50 开门前被拒 / 不可达(只记"还没开门")
· 登录途中网络断(密码没被否认)
· 绑定被拦(bind:密码其实是对的,问题在账号绑定)
· 门户维护页(格式不认识)
│
谁消费这个状态 · 主页横幅①:"密码还没验证过/可能改过了 — 去改一下"
· 成功页文案:未验证时如实说"明早首试真验证"
· 失败通知只在 未验证/被拒 时出现
· tries=0 早晨 + 未验证 → "今早的网不是桂桂登的"横幅

附 A · 系统外力兜底矩阵

无守护/无托盘/无常驻是定稿决策 — 自动化的韧性全部由任务层与"下次打开"承担(PRD §8.5)

场景机制残余 / 备注
关机错过触发窗口错过补跑(StartWhenAvailable)+ 开机补跑(默认开)开机即登,窗口内幂等
任务没建成 / 被删GUI 启动自动对齐(只恢复已选配置)+ 指引通知永不开 GUI = 沉默死亡;设置页状态行是唯一可见性
杀软拦任务创建降级注册(去开机触发保每日定时)→ 放行后自动升级设置页可一键重建(仅点击触发)
进程被后台杀执行体是独立短进程;窗口内下一拍(5 分钟)自然补GUI 被杀不影响自动化
exe 被杀毒清理任务指向失效自动判坏,下次对齐重建同"任务被删"残余
系统时钟错乱—触发时刻与 06:50 锚点跟着错,接受
笔记本睡眠错过窗口唤醒触发(默认关,可开) + 唤醒补登 30s电池供电可能不唤醒
假期离校连续 2 天不可达 → 假期静默(每天 1 次,不通知)回校自动恢复
同账号多设备互踢下一拍自动补登可能反踢手机,拉锯无解,文档明示
数据目录被清回落首装单行道重来凭据在系统凭据管理器,不受影响
日志无限增长>90 天自动清理(仅桂桂自己目录)—
