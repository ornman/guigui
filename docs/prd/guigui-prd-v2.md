## 1. 一句话定位

> **每天 7:00 准时上网,比你自己记得还牢。**

校园网自动登录助手 — Windows 桌面应用。产品人格化,不强调"工具",强调"我每天替你记着"。

## 2. 用户与场景

### 2.1 用户

**本校单个学生**。使用笔记本或台式机,Windows 10/11,有图形界面偏好。

### 2.2 三个场景

| 场景 | 时段 | 期望行为 |
|---|---|---|
| **同住 · 早晨 7:00** | 工作日 5 天 | 每天 7:00 起床开电脑,那一刻就是联网状态 |
| **实验室 · 8:00 上班** | 8:00-11:50,14:00-17:30 | 离开/回来切换时,第一个时刻能立即可用 |
| **假期 · 全天在家** | 寒暑假留校 | 长时间空闲后第一次开盖能用,不要高频探测 |

**主用户**是场景 1;场景 2/3 是**预留接口**,后续版本迭代。

## 3. 核心功能

### 3.1 自动登录(主轴)

- **每天固定时间**(用户从时间槽选一个,不是填 HH:MM)
- **开机登录**(默认开,补用户早于设定时间开电脑)
- **其他机制叠加**(默认关):WiFi 兜底 / 白天巡逻 / 唤醒触发 — 见 §6

### 3.2 WiFi 兜底(选连接)

- 认证服务器不可达时,系统**扫描附近 WiFi**
- GUI 弹出候选列表(带信号强度)
- 用户**从列表选一个**,**不用记 SSID 名字**
- 后续自动用该 SSID 兜底

### 3.3 GUI = 唯一的固定窗口(单卡片拟物形态)

- **全应用只有一个窗口**:560×640 固定长方形卡片,本身就是整个页面
- **伪透明,不是真透明**:磨砂壁纸效果直接烘焙进窗口背景(渐变 + 边框高光 + 玻璃投影),
  不依赖运行时 backdrop 采样 — 原型即所见;打包后用 Win11 Mica/Acrylic 材质落地同等观感
- 标题栏:**最小化 / 关闭**两个按钮 — 两者都进入"后台静默"(无托盘图标,以一枚小胶囊浮标收尾,点击还原),区别仅在胶囊文案
- 卡片内所有导航是**视图切换**,不弹二级窗口、不弹系统对话框

### 3.4 Bot(桂桂吉祥物,界面的情绪层)

- 形象:黑色 blob(与主文字同色),**原创折线眼系**(sleep=— / idle=上斜折线 / happy=上扬三角
  / sad=下斜折线 / cry=sad+泪圆点),`stroke-linejoin:miter` 显出几何尖角 — 交互语言参考
  grok-icon-study(眼睛情绪 + 弹簧动画 + 节拍式微表情),**几何 100% 原创,不复制 xAI 几何**。
  整张脸去嘴,只用眼睛+泪点承担情绪 — 更干净
- **初始化链路**:blob 居中沉睡(闭眼折线)— 程序初始化完成 → **苏醒动画**(拉伸弹起 +
  折线从两端描画至完整,不是直接出现)→ 停靠问候标题左侧
- **庆祝动效**:登录成功时 bot 恢复首次仪式级大尺寸(居中上方)+ 大头左右摇晃(sway),
  配 happy 折线眼
- **节拍式微表情**(学到的风格):所有非 sleep/cry 状态的 bot 由两个独立时钟驱动 —
  **gaze 游走**(2-4s 一次,小幅±2px 平移)和 **blink**(4-6s 一次,150ms 闭眼),
  让 idle 不是死的。状态切换走 200ms 折线坐标 lerp(不是瞬切),是连续 morph
- **情绪即状态**(眼睛 + 泪点表达,全走色彩纪律内的黑白):

| 状态 | 情绪 | 表现 |
|---|---|---|
| 初始化中 | 沉睡 | 浅∪闭眼弧,字幕"正在初始化…" |
| 已登录/操作成功 | 高兴 | 大^弧眼 + 大笑嘴 + 弹跳一下 |
| 已连网未登录 | 沮丧 | 垂眯眼 + 撇嘴 |
| 不可达 | 委屈 | 垂眯眼 + 撇嘴 + **泪滴循环滑落** |
| 日常待命 | 平静 | 浅^眯眼 + 微笑 |

- 问候语按打开时间:**早上好 / 下午好 / 晚上好**(11:00 / 18:00 分界)

### 3.5 内嵌日志

- 主面板右上角"日志"按钮
- 弹出滚动日志视图,彩色高亮(成功/警告/失败)
- 支持过滤(级别/时间)和导出(.txt)

## 4. UX 全链路

四条设计原则:**仪式分级**(睁眼仪式只发生一次)、**主面板 = 一句人话 + 三行服务条**(桂桂用自己的口吻说话)、
**问题即情绪 + 修复 ≤ 2 步**、**通知是唯一主动触达**。

### 4.0 链路总览

```
打开窗口(唯一的窗口)
  │
  ├─ 首次(无配置)
  │    完整仪式:blob 居中沉睡 → 弧线浮起 → 弹跳 → 停靠标题左侧(约 2s)
  │    ├─ ①已登录 → [开启每日自动登录] → 只滑出密码一格(学号已识别)
  │    ├─ ②未登录 → 填学号/密码 → 立即登录
  │    └─ ③不可达 → 引导页(诊断 → 扫 WiFi 选连接 / 重新检测 / 先填资料)
  │         └─ 连上后自动转 ① 或 ②
  │    → 恭喜登录成功~(bot 大头摇晃 + "每天 07:00 帮你自动登录" + 可关闭窗口)
  │    → 底部一行:高级设置(时间/兜底/巡逻的唯一修改入口)
  │
  ├─ 日常(已配置,无问题)
  │    快速苏醒(0.6s):标题左侧小 bot 浮起 → 直接主面板(平静)
  │
  └─ 出问题被打开(已配置)
     bot 情绪自动反映:未登录=沮丧 / 不可达=委屈
     主面板状态行换警告色,主按钮即修复动作
```

### 4.1 首次打开:配置仪式链(只发生一次)

1. **完整仪式**(约 2s):blob 居中沉睡 → **苏醒动画**(拉伸弹起 + 眼嘴弧线依次描画,睁眼有过程)
   → 弹簧弹跳停靠 → 按时刻问候。仪式结束时桂桂顺带完成网络体检,**按体检结果三分流**(见 4.1.1)。
   GUI 使用频率极低(打开多为调整配置),首次配置完成后**永远是日常页**。
   **首次仪式 ≠ 开机等网络**:「开机太快·等网络」是已配置用户每天的开机场景,**没有典礼**:
   桂桂保持睡着(不睁眼),字幕"校园网 06:50 才开门,桂桂在门口等着… 每 30 秒看一次",
   网络就绪直接落**日常主页**——首次是"桂桂醒了认识我",开机等是"桂桂睡着也会办事"
2. **三状态分流**(见 4.1.1)
3. **一页交钥匙,再无第二行**(收集学号/密码不可避免,就把它做成最轻的一步;页面只留必要件):
   状态行"Campus-WiFi · 已连上 · 学号已识别 ✓"(学号已预填,可改)+ 学号/密码两格 +
   唯一大按钮「开启每日自动登录」。无副标语、无说明行、无「高级设置」入口(它属于日常页);
   填表就是"开启"这个动作本身的一部分,不做成向导、不单独跳页
4. **密码框只带小眼睛**:框内**明文/隐藏小眼睛**(输错能自查);为空点击按钮只给一句
   内联温柔提醒"密码还没填呢"(不弹窗、不标红恐吓)
5. **提交按钮的等待态(硬性)**:点击「开启每日自动登录」后按钮**置灰禁用 + 旋转图标 + 文案变"验证中…"**,
   结束前不可再点 — 在线验证全程 5~15 秒,等待中重复提交等于并发跑两次"注销→登录",属正确性问题不只是视觉;
   **仅登录验证成功才进庆祝页**(庆祝只给真实成功),失败则按钮恢复 + 就地内联报错
6. **登录成功即庆祝**:bot 恢复首次仪式级大尺寸(居中上方)+ 大头摇晃 + **颜文字粒子**
   (canvas-confetti `shapeFromText` 喷 `~(￣▽￣)` 与 ♥,紫粉配色;**vendor 本地加载,不依赖 CDN**);
   标题"网,已经帮你连好啦",正文"明早 07:00,桂桂会提前替你登好 — 你只管睡到自然醒";
   提示**只保留一句**:"✓ 现在就可以关闭窗口,桂桂在后台守着"(其余信息一律不给,防冗余)
7. 底部一行小字「高级设置」— 时间/兜底/巡逻/账号密码的**日常修改入口**(对齐原版全部功能,见 §5)
8. 文案原则:按钮以核心功能命名("开启每日自动登录"),**禁用"保存配置/完成配置"类系统腔**
9. **粒子限定在卡片内**:canvas-confetti 使用窗口内建画布(`confetti.create`)渲染,
   配合窗口 `overflow:hidden`,特效永不溢出卡片圆角
10. **登录失败内联化**:认证被拒不再单独占页,登录表单内联警告**按服务器真实拒绝分三态措辞**
   (2026-09-06 隔离测试床实测,见 4.1.2),改完直接重试(视图总数 9 → 8)

> 时间槽细节(在高级设置内):校园网默认 **06:50** 开门(服务器此前不接受认证,
> 与真实日志吻合:06:25/06:40 unreachable、06:55 即通),此知识放微文案告知用户;
> 登录时间**输入框常驻**(两位一格,数字键直入、自动跳格、范围约束,不用原生控件也不用滚轮
> — 滚轮是触屏隐喻,桌面键入最快),旁边「常用时间」药丸一键填充;无置灰槽位、无「自定义」两步。

#### 4.1.1 三状态

| 状态 | 仪式落地页 | bot 落地表情 | 首屏 | 主按钮 |
|---|---|---|---|---|
| 可达+已登录 | v-ok 一页交钥匙 | 高兴 | "已经连上啦。"学号已识别并预填,密码留一格 | 开启每日自动登录 → 庆祝页 |
| 可达+未登录 | v-login 登录表单 | 沮丧 | "连上了,但还没登录。" | 立即登录 → 庆祝页 |
| 不可达 | v-guide 排查引导 | 委屈(哭) | "呜…路走不通。" | 进入引导页(4.3) |

> 首次仪式与日常状态同源:同一份网络体检结果决定仪式落点。
> **首装链路是单行道**:掉线/不可达分支落地的 v-login/v-guide 隐藏「‹ 返回」
> (body.setup 标记控制;日常维修场景从主页进入时返回正常可用)。

凭据抓取边界(协议事实):**学号在"已登录"状态下可自动识别** — Dr.COM 的
`chkstatus` JSONP 接口会返回当前会话的账号(DDDDD 字段),状态①直接回显、无需填写;
**密码任何接口都不返回**,只能用户填一次(填完桂桂已持有,无爬取收益)。
2026-08-30 已实测验证:登录态下 `GET /drcom/chkstatus?callback=dr1003`(80 端口)
返回 62 字段会话 JSON,`uid` 与 `AC` 即登录账号(按源 IP 会话识别,NAT 后多设备同值);
全部字段无任何密码/凭据残留,密码边界成立。
同日二次实测:门户首页(注销页)直接内嵌 `uid` 变量与**空 `pwd` 槽位**(模板留位、
服务端永不填充),且所有响应无 Set-Cookie — 密码边界再证,账号可从服务器零配置获取。
服务器可自描述:同页下发运营商后缀表(校园用户 ''/校园电信 `@dx`/校园联通 `@lt`
/校园其他 '',默认校园用户),v2 运营商后缀应取自服务器而非硬编码(v1 硬编码「电信→无后缀」
与服务器配置不符,裸学号仅默认运营商可登录)。
不依赖门户漏洞:漏洞会被修补,且产品不能建立在对第三方系统的非授权利用上。
每个状态视图底部必有「高级设置」文字链(二级视图,卡片内切换,带返回)。

**2026-09-06 隔离测试床实测回填(墙口直连,不借道共享路由)**:

- **运营商选项两页一致**:登录页与注销页内嵌的 carrier 配置**完全相同,均为 4 项**
  (校园用户 ''/校园电信 `@dx`/校园联通 `@lt`/校园其他 '',defaultID=1)。
  「中国移动/中国广电」**不在门户登录选项中** — 套餐口径(营业厅/自助平台)与登录
  后缀是两套体系;办了移动/广电套餐的学生,登录选项仍在这 4 项里按实际开通情况选择。
- **登录请求中运营商的唯一落点 = 学号 + 所选后缀**(门户前端 JS 实读确认;错误码
  语义亦从协议层反证,与现实现一致)。
- **服务器拒绝文案三态**(样本各一,措辞以服务器原文为准):
  | 服务器返回 | 含义(实证推断) | 用户看到的文案 |
  |---|---|---|
  | `userid error1` | 账号+所选运营商组合不存在 | "学号或运营商选错了,核对一下" |
  | `userid error2` | 账号存在、密码不对 | "密码不对,改一下再试" |
  | `bind userid error` | **密码正确**,但账号绑定/接入区域被拦 | "密码是对的,但这个账号被绑在别处/受限 — 去自助服务平台看看绑定" |
  其他返回原样展示。**"密码可能改过了"不再作为一刀切文案**。
- chkstatus 双态验证:未认证墙口返回空;在线会话返回该会话学号(按源 IP 识别)。
- 页面编码细节:登录页 UTF-8 / 注销页 GB2312(探测逻辑不受影响,标题判别两页均正确)。

#### 4.1.2 提交后的验证阶梯(产品行为,2026-09-06 定稿)

**原则:凭证神圣 — 密码必须经服务器真验证才算数;明确被拒绝不入库。**
严格验证自动执行,不设"严格/宽松"选项(验证一生只在首装/改密发生,且用户在场)。

```
提交(按钮进入等待态,不可重复点击)
  │
  ├─ 当前未登录 → 直接真登一次
  │
  ├─ 当前已登录 → ① 注销当前会话(网络会断几秒,提交上方一行小字如实告知;
  │                若线上是别的学号,注明"现在线上的是 6503…21,验证时会先注销它")
  │             ② 等状态翻转(最多几秒)
  │             ③ 真登一次(刚注销会被限流,等 4 秒重试一次)
  │
  └─ 五路结果:
     ├─ 登录成功 → 密码入库(标记"已验证")→ 庆祝页
     ├─ 密码不对(error2)→ 用旧密码把网接回来 + 按钮恢复 + 内联"密码不对";
     │    首装没有旧密码时如实说"验证没过,网先断着,输对马上通"
     ├─ 账号/运营商不存在(error1)→ 同上恢复,内联"学号或运营商选错了"
     ├─ 绑定被拦(bind)→ 密码是对的,指引自助平台查绑定
     └─ 网络中途够不着 → 密码存为"未验证",明早首试真验证,失败弹通知提醒
```

- **06:50 开门前提交**:被拒不判"密码错误",提示"还没到开门时间(06:50),密码先存着,
  明早自动验证"(存为未验证)
- 门户维护页(服务器返回不认识的格式):如实展示,不猜测原因
- **日常改密码/改学号/改运营商走同一阶梯**(入口见 §5),验证通过才替换旧凭据;
  学号变更时内联确认"学号将从 A 改为 B,密码会迁移到新学号"(防手滑,换号会清旧凭据)

### 4.2 日常打开:快速苏醒 + 一句人话

- 0.6 秒:右上角小 bot 闭眼→睁眼,无居中仪式,直接主面板
- **状态即标题**(问题状态不允许只换小字):掉线/不可达时,页面最大的 h1 直接换成状态句 —
  掉线「呜,刚才掉线了。」/ 不可达「现在连不上校园网。」(正常态才是时刻问候);
  版式不变、分量变重,安静但不可能错过。配套:问候行下**状态行**(同登录页组件:
  掉线=紫点「校园网 · 刚刚掉线了」/ 不可达=琥珀点脉动「认证服务器 · 不可达」)+
  主按钮同色描边(紫=立即登录,琥珀=去排查)— 修复动作与状态同色。无 4px 装饰条
- **问候行下只跟一句桂桂的话**(衬线、状态驱动,禁止再堆第二行说明文字):
  正常「网的事交给我,你放心忙~」/ 掉线「刚才网断了一下,别担心,登一下就回来。」/
  不可达「现在够不着校园网,我陪你查查看。」/ 重登成功「刚刚把网帮你接回来啦 ✓」
- **服务条三行,同一种行语言**(标题 + 灰色详情,与设置页行同构,不混两种行样式;
  产品自解释语「校园网自动登录助手」只属于首装页;具体时间全页只出现一次):
  1. 自动登录:明早 07:00 替你登 · 到点前 30 分钟开始试(行尾开关)
  2. 网络:已连上 Campus-WiFi ✓
  3. 昨晚:07:00 第一次就登好了 ✓
- **操作两级分层**:「立即重新登录」= 描边次级按钮;「高级设置」= 其左下方的小文字链,
  视觉权重明显不同,不再同级打架
- **问题横幅(仅两种,有动作要做才出现,2026-09-06 定稿)**:
  ①「密码还没验证过/可能改过了 — 去改一下」(凭证未验证或曾被告拒);
  ②「今早没登上 — 去改一下」(当日登录失败)。
  横幅点击**直达改密页**,改对即消失。会话自然续期的正常早晨**永无横幅**;
  线上是他人学号只如实写进日志(历史日志可见),不横幅不通知 — 横幅疲劳会杀死整个提醒机制
- **主按钮三态,文案与行为必须一致**:正常=「立即重新登录」(一键) /
  未登录=「立即登录」(一键,带等待态) / 不可达=「去排查」(进引导页);
  所有发网络请求的按钮等待中置灰+旋转,不可重复点击(同 4.1 第 5 条)
- **主页快捷总开关**:「自动登录」行右侧开关;状态由开关自身表达,
  文字只讲服务(开="明早 07:00 替你登…"/关="已关 · 想让我开工随时说"),
  桂桂换入睡表情、口吻行变"好,我先歇着,想我了再开";与设置页「后台自动化」双向同步
- **日志钉底 + 历史日志**:今天的日志(3 行)固定在卡片底部,块内**右下角**一枚
  「历史日志 →」进入**历史日志视图**(v-log):按天分组的完整运行记录,
  含假期静默天的"每天只探 1 次,不吵你"
- **无催补提示框**:首装时密码必填,日常页不再出现"还差一步"式催补框

### 4.3 不可达引导页(自动诊断链,不是错误码)

```
① 当前网络识别(自动):"连的是「xxx」,像热点,不是校园网"
   → 扫描列表(带信号强度),点一下即切换 — 这就是 WiFi 兜底的选连接入口
② 已是校园网仍不可达 → "可能服务器维护" → [重新检测]
③ 降级兜底:"先填资料,连上后桂桂自动帮你登录" → 跳②表单
```

bot 全程委屈但不指责;每步都给可点的动作。

### 4.4 修复路径(全部 ≤ 2 步)

| 问题 | 路径 | 步数 |
|---|---|---|
| 掉线(未登录) | 主面板 [立即登录] → 成功弹跳 | 1 |
| 密码被拒(error2) | 通知/横幅点击 → 改密页改对 → 重验入库 | 2 |
| 学号或运营商选错(error1) | 改密页内联提示 → 改对重试 | 2 |
| 账号绑定被拦(bind) | 改密页指引自助平台查绑定(桂桂侧无解,如实说) | 1 |
| 不可达 | [去排查] → 引导页点一个 WiFi | 2 |
| 开机太快网络未就绪 | 无典礼:桂桂睡着,"校园网 06:50 才开门,桂桂在门口等着… 每 30 秒看一次",开门即登、落日常主页 | 0 |

### 4.5 通知链路(后台唯一主动触达,全部可点击)

| 事件 | 通知 | 点击后 |
|---|---|---|
| 断 → 通 | "已连上 ✓"(每天最多 1 次) | 打开主面板 |
| **开门后明确被拒**(06:50 后第一次"密码不对"类失败) | **"登录失败,密码改了?"— 当拍即弹,不等凑满 3 次**(每日最多 1 次,防刷屏) | 打开改密页(三态文案见 4.1.2) |
| 服务器维护中(连续异常 ≥3 拍) | "桂桂一直登不上,点开看看" | 打开主面板 |
| 安全软件拦了定时任务 | "定时任务被拦,点这里重建" | 打开设置页(**仅用户点击才重建**,绝不后台静默重建) |
| 一切正常 | **永不通知** | — |
| 假期静默中 | **不通知** | — |
| **06:50 开门前的任何失败** | **不通知**(只记"还没开门",见 4.6) | — |

**开门锚点原则**:06:50(校园实测开门时间)之前的尝试被拒/不可达,一律视为"还没开门":
只记一条日志、下一拍再看 — 不判失败、不发通知、不降低密码可信度。
防止 06:30~06:50 窗口期错怪用户"密码改了"。(锚点行为待真机窗口期验证)

### 4.6 边界状态表

| 场景 | 行为 |
|---|---|
| 开机太快,网卡未就绪 | 等待态:**无典礼**,桂桂沉睡 + "校园网 06:50 才开门,桂桂在门口等着…"(开门即登,落日常主页,永不报错) |
| **06:50 开门前被拒/不可达** | 只记"还没开门,等下一拍" — 不判失败、不通知、不降密码可信度(防窗口期错怪用户) |
| 账号密码被拒 | 三态措辞(4.1.2 实测表):密码不对 → 改了再试;学号/运营商选错 → 核对;绑定被拦 → 指引自助平台 |
| **账号绑定被拦(bind,密码其实是对的)** | 桂桂侧无解,如实告知 + 指引自助服务平台查绑定(换绑/解绑后即恢复) |
| 密码错发生在在线验证中 | 尽力用旧密码把网接回来;首装没有旧密码时如实说"网先断着,输对马上通" |
| **线上是别人的学号**(共享路由/他人会话) | 日志如实记一行("线上的是 6503…21");不横幅、不通知;首装提交时如实注明"验证时会先注销它" |
| 用户想换学号/密码/运营商 | 设置页「账号与密码」→ 同一验证阶梯,验证通过才替换;换学号内联确认"学号将从 A 改为 B,密码会迁移" |
| 同账号多设备互踢(手机登门户踢掉电脑会话) | 下一拍自动补登(可能反踢手机),拉锯无解 — 已知边界,文档明示不做 |
| 服务器维护 | 主面板降级:"维护中,桂桂会一直试" |
| **假期/离校(连续 48h 不可达)** | **自动进入假期静默:心跳降频至每天 1 次,不通知**;窗口打开时 bot 委屈+"放假啦?回来再叫我" |
| 更换 WiFi 环境 | 引导页重新选连接(选连接免填名) |

## 6. 触发器模型(多层叠加)

用户配置了"每天 07:00",但实际触发器是**多层**叠加,每层独立可控。默认仅 L1+L2 开。

### 6.1 L1 起床窗口心跳(主轴,默认开)

用户设定一个时间点(默认 07:00),起床窗口 = **设定时间 ± 30 分钟**,窗口内每 **5 分钟**尝试一次,共 **6 次**。**任一次登录成功则立即结束心跳**,不再继续尝试。

**目的**:用户实际开电脑的时刻不固定(6:30 / 7:00 / 7:25 都有可能),用 6 次覆盖窗口保证一定赶上,同时不浪费资源 — 早登上了就不重复探测。

```
用户设定:07:00 → 窗口 = 06:30 – 07:30

  06:30  L1 心跳 1  → 探测 → 登成功? ──是──► 停  (后续 5 次取消)
  06:35  L1 心跳 2  → 探测 → 登成功? ──是──► 停
  06:40  L1 心跳 3  → 探测 → 登成功? ──是──► 停
  06:45  L1 心跳 4  → 探测 → 登成功? ──是──► 停
  06:50  L1 心跳 5  → 探测 → 登成功? ──是──► 停
  06:55  L1 心跳 6  → 探测 → 登成功? ──是──► 停

  6 次全部失败 → 进入 L3(若用户开启白天巡逻)
  07:30  窗口结束
```

**用户视角**:选一个时间点,桂桂在那前后的 30 分钟里会尝试 6 次,只要电脑开着,大概率在你需要用之前就登上了。

> **开门锚点(2026-09-06 新增)**:06:50 前的心跳若被拒/不可达,一律按"还没开门"处理 —
> 只记一条日志、下一拍再看;**不判失败、不发通知、不降低密码可信度**。
> 06:50 为校园实测开门时间(锚点行为待真机窗口期验证);窗口按默认 07:00 设定时,
> 后两拍(06:50/06:55)正好落在开门后,首拍(06:30)纯探路。

### 6.2 其他触发器(默认关)

```
L2 开机登录 ────── AtLogon ────────► [--ensure]  (补早于窗口开电脑)
L3 白天巡逻 ────── 每 30 min ─────► [--ensure]  (意外断网时恢复)
L4 WiFi 兜底 ───── 仅 L1/L2 不可达时 ► [--ensure 改用备用 WiFi]
L5 唤醒触发 ────── AtWake + 30s 延迟 ► [--ensure]  (笔记本睡眠唤醒)
```

**`--ensure` 静默执行体**:探测 → 必要时登录 → 状态翻转才通知。多个 `--ensure` 进程并发安全(原子写 `ensure_state.json`)。

> **注**:本节描述**产品行为**(什么情况下会触发登录),不涉及具体任务计划 API、PowerShell 脚本或注册表键。

## 7. 业务流程(2026-09-06 重梳理;交互图见 `flows/` 三张 archify 图:首装验证阶梯 / 凭证可信度 / 日常每拍;速览参考 `guigui-business-flow.html`)

### 7.1 首装(一次性)

```
打开桂桂 → 开机仪式(2s) → 网络体检三分流
  ├─ 可达+已登录 → 交钥匙页(学号已识别) ─┐
  ├─ 可达+未登录 → 登录表单 ────────────┤ 两者提交后走同一验证阶梯(4.1.2)
  └─ 不可达 → 引导页(诊断/选WiFi/重测/先填资料,连上后转上两者)
                                        │
                提交 = 按钮等待态(置灰+旋转+不可重复点击)
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 ▼ 在线:先注销→等翻转→真登一次                    ▼ 未登录:直接真登
                 │                                              │
     ┌──成功──┬──密码不对──┬──号/运营商错──┬──绑定被拦──┬──网络够不着──┐
     ▼        ▼            ▼               ▼            ▼            ▼
  密码入库   旧密码接回网   内联提示改对     指引自助平台   密码存"未验证"
  (已验证)  +内联报错      (恢复网络)      (密码其实对)   明早首试真验证
     │        └──────────── 改对重试(仍在等待态) ────────────┘
     ▼
  庆祝页(仅真实成功) → 注册每日自动化 → 日常页
```

### 7.2 日常(每天,后台自动)

```
每拍(窗口内心跳/开机/巡逻/唤醒共用同一执行体):
  总开关关 / 没存过凭据 → 直接退出
  │
  ├─ 网络栈未就绪 → 等门(30 秒一看,开门即继续)
  │
  ├─ 已在线 → 当日首次? → 收工:记日志/复位计数/线上学号如实记录
  │            └─ 桂桂没动手就在线 + 密码从未验证过 → 主页横幅"新密码存一下?"
  │            └─ 线上是别人的学号 → 只记日志,不横幅不通知
  │
  ├─ 未登录 → 真登(失败重试 N 次,登上即停)
  │     ├─ 成功 → 收工(密码标记"已验证")
  │     ├─ 被拒 → 06:50 前:记"还没开门"等下一拍(到此为止)
  │     │        06:50 后:记失败 + 密码标记"未验证" + **当拍即弹通知**(每日1次)
  │     └─ 服务器格式不认识 → 记异常,连续≥3拍才通知
  │
  └─ 不可达 → (兜底WiFi开启时)切兜底再试一轮 → 仍不可达:
        连续≥2天 且假期静默开 → 假期静默(每天1次,不通知)
        否则记"连不上校园网",不通知
```

### 7.3 凭证可信度(贯穿所有流程的单一真源)

| 动作 | 可信度 |
|---|---|
| 验证阶梯真登成功 / 日常真登成功 | → **已验证** |
| 服务器明确拒绝(密码不对) | → **未验证** |
| 06:50 前被拒 / 不可达 / 网络中途断 | → **保持不变**(不冤枉密码) |
| 主页横幅、失败通知、改密引导 | 全部由"未验证/当日失败"这两个事实驱动 |

### 7.4 用户主动改凭据(设置页「账号与密码」)

改密页(学号回填/密码留空/运营商四选)→ 提交(等待态)→ 同一验证阶梯 →
验证通过才替换旧凭据(换学号=迁移+清旧,内联确认);被拒不入库、网络尽力恢复。

## 8. 验收标准(可量化)

| 编号 | 验收项 | 指标 |
|---|---|---|
| AC-01 | 核心场景 | 7:00 起床开电脑,30 秒内能 ping 通 baidu.com |
| AC-02 | 首次体验 | 首装三路径(已连 / 未登录 / 不可达)均有明确引导,无报错弹窗 |
| AC-03 | WiFi 兜底 | 校园网服务器不可达时,系统扫描并列出 ≥5 个候选 SSID,用户从列表选择,无需手填名称 |
| AC-04 | 通知去重 | 已登录不通知;每天"断→通"仅通知 1 次;失败 3 次后通知 1 次不刷屏 |
| AC-05 | 后台静默 | 程序不在托盘,关窗后内存占用 < 50MB,空闲时 CPU 0% |
| AC-06 | GUI 不打扰 | 用户未主动打开时,主进程不拉起,任务计划触发独立短进程 |
| AC-07 | 日志可读 | 主面板内嵌日志查看器,支持过滤(级别/时间)和导出 |
| AC-08 | 仪式分级 | 睁眼仪式与完成光晕脉冲只发生一次(首次配置),日常打开 ≤0.6s 直达主面板 |
| AC-09 | 修复路径 | 任何问题状态,开始修复 ≤2 步;等待网络 0 步(自动) |
| AC-10 | 假期静默 | 连续 48h 不可达自动降频至每天 1 次心跳且不通知;回校后自动恢复 |

## 8.5 系统行为与风险清单(内部边界,不进 UI)

**原则:凡触碰系统的操作,必须满足其一 — 用户开关可关 / 用户点击触发 / 文档写明风险与残余影响。**

### 8.5.1 可自动执行(静默正确,无破坏性或有界自愈)

| 操作 | 边界理由 |
|---|---|
| 网络探测与三分流路由 | 纯只读 |
| 06:50 开门锚点抑制 | 保护性,无副作用 |
| 在线注销→真登验证 | 一生两次(首装/改密),用户在场,提交即授权 + 一行断网告知 |
| 凭证可信度维护/日志/状态 | 本地数据 |
| 开门后被拒立即通知 | 受「弹通知」总开关管辖 |
| 只读查线上学号 | 无副作用 GET |
| GUI 启动时任务对齐 | 只恢复用户已选配置,不新增任何东西 |
| 日志 >90 天清理 | 只动桂桂自己目录的文件 |

### 8.5.2 必须用户动作触发

改学号/密码/运营商(表单提交即授权) / 切兜底 WiFi(默认关) / 定时任务一键重建(仅点击) /
各开关裁量(总开关/通知/巡逻/唤醒/开机补跑/假期静默) / 卸载删凭据(询问)。

### 8.5.3 残余风险(明示不解)

- **永不开 GUI 的沉默死亡**:任务被删且用户不打开桂桂 → 无自动登录且无人提醒;
  设置页任务状态行是唯一可见性(打开时)。无守护进程是定稿决策(AC-05/06)。
- 系统时钟错乱 → 触发时刻与 06:50 锚点跟着错(不解,接受)。
- 笔记本电池睡眠可能不唤醒错过窗口(WakeToRun 已开,文档说明)。
- 同账号多设备互踢拉锯(手机门户 vs 电脑,4.6)。
- 学校侧风控/锁定策略未知 — 重试节奏保守(3 次×5 秒,拍间 5 分钟),绝不暴力尝试。
- 06:50 开门为校园经验值,锚点行为待真机窗口期验证。

### 8.5.4 测试床与环境事实(工程备忘)

- 隔离测试床 = 笔记本网口直插墙口(独立会话),共享路由上游的全屋会话**绝不触碰**;
  双宿主开发机需:WiFi 跃点优先(保开发机联网)+ 门户 IP 主机路由钉网口(保测试隔离)。
- 2026-09-06 实测:运营商 4 项两页一致;拒绝三态 error1/error2/bind;chkstatus 双态正常;
  登录页 UTF-8/注销页 GB2312;**测试账号从墙口登录被 bind error 拦(密码正确),
  属账号侧绑定/区域限制 — 待自助平台解绑后补测"在线注销→真登"全阶梯**。

## 9. UI 视觉系统

参考 https://github.com/blessonism/grok-icon-study 风格。**已拍板:Glass Subtle + Serif**。

### 9.1 色彩纪律(硬规则)

1. **一个控件一种颜色** — 按钮一律纯黑单色,无渐变、无彩色阴影
2. **全局唯一强调色** — 紫色,只用于:状态点、开关开启态、聚焦环、环境光晕
3. **唯一暖色例外** — 琥珀,只用于"不可达"状态点
4. 中性色全部向紫色 hue 微量染色,禁止纯 #000 / #fff

### 9.2 调色板

| 用途 | 值 | 纪律 |
|---|---|---|
| 背景 | `oklch(97.5% 0.008 295)` | 白底(紫染) |
| 主文字/按钮 | `oklch(23% 0.015 295)` | 近黑(紫染) |
| 副文字/弱文字 | `oklch(45% …)` / `oklch(60% …)` | 灰阶(紫染) |
| 强调紫 | `oklch(58% 0.15 295)` | 仅状态点/开关/聚焦环/光晕 |
| 例外琥珀 | `oklch(72% 0.12 70)` | 仅"不可达"状态点 |
| 玻璃面 | `oklch(100% 0 0 / 0.62)` + blur(36px) | 全页唯一容器 |

### 9.3 字体

- 标题/正文:思源宋体 / Noto Serif SC(Georgia / Recoleta 兜底)
- 微标签/数字:Inter(仅 uppercase 小标签与时间数字)
- 正文 `16px / 1.75`,标题 `30px / 600`,微标签 `11px / 600 / letter-spacing .14em`

### 9.4 形态

- **一张卡片**:全页唯一玻璃容器(圆角 20px),内容用留白+细分隔线组织,不嵌套
- 圆角:卡片 20px / 输入 12px / 时间槽与按钮 10-12px / 开关胶囊
- 间距:卡片内 36px,区块间 20-26px

### 9.5 选中态与动效

- **选中态**(时间槽/WiFi 列表):**紫→粉渐变描边**,以 opacity 渐显过渡(约 0.35s),配淡紫光晕 — 用户指定,是单色纪律的唯一例外
- 200-400ms,ease-out,无 bounce / elastic
- 只用于:状态变化、过场、按钮 hover 微抬升
- 必须尊重 `prefers-reduced-motion`(系统开启时全部禁用)
