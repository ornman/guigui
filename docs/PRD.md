# PRD: SchoolAutoLogin 桌面应用

> 校园网（Dr.COM）自动登录桌面工具，带 GUI 界面、系统托盘、轮询断网重连、定时登录。

---

## 1. 背景与目标

### 现状

当前 `auto_login.py` 是纯脚本，通过 `config.json` 配置，PyInstaller 打包为 exe。用户需要手动编辑 JSON 文件来修改配置，无 GUI，定时登录依赖 Inno Setup 安装时固定创建的 Windows 任务计划。

### 目标

做一个轻量 Windows 桌面应用（单 exe），用户通过 GUI 完成所有配置和操作，无需手动编辑任何文件。

**设计原则：**

- 轻量：仅依赖 Python 标准库 + `customtkinter`（一个 pip 包，基于 tkinter）
- 单进程：GUI、托盘、轮询都在一个 exe 里
- 零端口：原生桌面窗口，禁止 Web Server / localhost 方案

---

## 2. 技术栈

| 组件 | 选择 | 理由 |
|------|------|------|
| GUI 框架 | `customtkinter` | 现代外观，基于 tkinter，单 pip 包 |
| 系统托盘 | `pystray` + `Pillow` | 轻量，纯 Python |
| 后台任务 | `threading.Thread` | 标准库，无需额外依赖 |
| 定时登录 | Windows 任务计划程序（`schtasks`） | 系统原生，关了 app 也能执行 |
| 开机自启 | 注册表 `HKCU\...\Run` | 标准做法 |
| 通知 | PowerShell WinRT（现有实现） | 已验证可用 |
| 打包 | PyInstaller + Inno Setup | 与现有流程一致 |
| 配置存储 | `config.json` | 与现有格式兼容 |

**新增 pip 依赖：** `customtkinter`, `pystray`, `Pillow`

## 3. 用户流程

### 3.1 首次使用

```
双击 exe → 打开主窗口
→ 填写：运营商（下拉选择）、学号、密码
→ 点击「保存」→ 配置写入 config.json
→ 点击「立即登录」→ 执行登录
```

### 3.2 日常使用

```
双击 exe → 主窗口（已加载配置）
→ 手动登录 / 修改设置 / 最小化到托盘
```

### 3.3 后台模式（轮询开启时）

```
关闭主窗口 → 最小化到系统托盘
→ 后台线程每 N 秒检测网络
→ 断网 → 自动执行登录流程
→ 右键托盘图标 → 显示状态 / 打开主界面 / 退出
```

### 3.4 定时登录（独立于 app）

```
在设置中配置时间（如 06:55）→ app 创建 Windows 任务计划
→ 每天 06:55 系统自动执行 exe --silent
→ exe 以静默模式运行（无窗口），仅通知结果
→ 无需 app 在运行
```

## 5. UI 设计规范

### 5.0 设计理念：这个界面应该让人感觉什么？

**关键词：克制、精密、有态度。**

不是花哨，不是酷，是「这个工具的主人品味在线」。像一个设计师给自己做的内部工具——不讨好任何人，但每个看到它的人都想问「这是用什么做的」。

设计的目标不是「好看」，是**让人信任**。用户把学号密码交给一个工具，界面得让人觉得「这东西靠谱」。

---

### 5.1 风格定位：毛玻璃 × 新粗野主义

不是两种风格简单叠加。是**用粗野主义的骨架，穿毛玻璃的皮肤**。

- **粗野主义提供结构**：硬边、粗线、大胆的字体对比、拒绝圆滑。这是态度。
- **毛玻璃提供氛围**：层叠的灰度、顶部高光线、边缘的微光感。这是温度。
- 两者结合 = 不冰冷也不花哨，像一个有棱角但打磨过的人。

**反面教材：** 圆角按钮 + 微阴影 + 蓝紫渐变 = 典型的 AI 生成模板。我们的目标是做出来像某个独立设计工作室的作品。

---

### 5.2 色彩系统

#### 色彩哲学

色彩不是装饰，是信息层级。这个工具只有 7 种颜色，每种都有且仅有一个职责。

主色调选紫色不是随意的——紫色在深色界面上有天然的「科技感」和「神秘感」，但不是那种廉价的赛博朋克紫，是冷静的、几何的紫。

#### 色板

| 色值 | 角色 | 用途 | 占比 |
|------|------|------|------|
| `#0a0a0a` | 深底 | 窗口背景 | 60% |
| `#141414` | 表面 | 卡片、容器 | 25% |
| `#222222` | 结构线 | 边框、分割线 | 5% |
| `#e0e0e0` | 正文 | 所有可读文字 | 8% |
| `#666666` | 辅助文 | 标签、placeholder、状态 | 微量 |
| `#7c3aed` | 强调 | 按钮、焦点、Tab 指示器、状态点 | 微量 |
| `#000000` | 阴影 | 按钮偏移阴影 | 微量 |

> **关键原则：** 强调色（紫）永远是小面积出现。大面积的紫 = 廉价。一个按钮、一条指示线、一个焦点边框——仅此而已。

#### 灰度的选择

注意三个灰色不是随便选的：

- `#0a0a0a` 而不是 `#000000`——纯黑太硬，眼睛不舒服
- `#141414` 而不是 `#181818`——表面和背景的对比要微妙，不要一刀切
- `#222222` 而不是 `#2a2a2a`——边框要可见但不抢戏

这三个灰度之间的关系是：**等差数列**（10, 20, 34 十六进制），不是随便挑的。等差产生节奏，节奏产生高级感。

#### 文字色不是纯白

`#e0e0e0` 而不是 `#ffffff`。纯白在深色背景上像灯泡刺眼。`#e0e0e0` 是暖白，阅读舒适，不疲劳。这是排版设计的基本功。

---

### 5.3 字体与排版

#### 字体选择

| 用途 | 字体 | 理由 |
|------|------|------|
| 品牌标题（英文） | **Segoe UI** Bold | 几何感强，Windows 原生，不圆滑 |
| 中文正文 | **等线 (DengXian)** | 笔画硬朗，与 Segoe UI 气质统一 |
| 按钮文字 | Segoe UI Semibold | 比正文轻一级，不抢标题的视觉重量 |
| 辅助文字 | DengXian / Segoe UI | Regular weight |

**不用 Microsoft YaHei**——它是圆体，笔画末端有倒角，和粗野主义的硬朗气质冲突。等线的笔画是几何的、干脆的。

**不用 Impact / 黑体**——标题虽然要大胆，但这个工具的体量撑不住那么重的字体。Segoe UI Bold 在 28px 时已经足够有存在感，而且不会让整个界面头重脚轻。

#### 字号层级（严格的视觉阶梯）

```
品牌标题     28px Bold        ← 整个界面最重的元素，视觉锚点
副标题       12px Regular     ← 极小，和标题形成夸张的对比
Tab          16px Bold        ← 清晰可点击
表单标签     11px Bold        ← 小而有力，不占空间
输入框文字   14px Regular     ← 可读性优先
按钮         15px Semibold    ← 比标签重，比标题轻
状态栏       11px Regular     ← 最安静，不参与视觉竞争
```

**核心法则：最大和最小的字号之间差距越大，设计感越强。** 28px 的标题旁边放 11px 的标签，这种极端的对比是设计感的来源。如果标题 20px、标签 14px，差距太小，看起来就像没设计过。

#### 文字间距

- 品牌标题：`letter-spacing: 2px`——拉开字距，增加呼吸感，提升品质感
- 按钮文字：`letter-spacing: 4px`——按钮文字像标题一样对待，拉开间距
- 其他文字：默认间距

#### 对齐

**全部左对齐。** 不居中。

居中对齐是「模板感」的根源。左对齐产生一条明确的左边线，所有元素对齐到这条线上——这是排版的基本功。杂志、报纸、好的 App，正文几乎全是左对齐。

#### 间距系统（8px 基准网格）

所有间距都是 8 的倍数：`8, 16, 20, 24, 28, 32`。

| 场景 | 间距 | 说明 |
|------|------|------|
| 卡片内边距 | 28px | 比常见的 24px 多 4px，多一点奢侈感 |
| 标题到副标题 | 2px | 极度紧凑，把两个文本绑在一起成为一个视觉单元 |
| 副标题到分割线 | 14px | 让标题块有完整的呼吸 |
| 分割线到 Tab | 14px | |
| 标签到输入框 | 4px | 标签属于输入框，所以紧贴 |
| 输入框之间 | 8px | 同类元素间距最小 |
| 输入框到按钮 | 20px | 重要交互前给足呼吸空间 |
| 两个按钮之间 | 8px | 并列关系 |
| 按钮到状态栏 | 自动（flex） | 剩余空间全部吃掉 |

#### 卡片结构

整个界面只有一层卡片——没有卡片套卡片。卡片是毛玻璃感的载体：

```
背景 #0a0a0a
  └── 卡片 #141414, 边框 2px #222222, 无圆角
       ├── 顶部 1px 高光线 #2a2a2a（毛玻璃折射）
       └── 顶部 3px 紫色条（品牌标识）
```

卡片上面先是一条 3px 的紫色条——这不是装饰，是**品牌标记**。用户扫一眼就知道这个窗口是什么。紫色条直接贴在卡片顶边，不留间距。

高光线是 1px 的 `#2a2a2a`，比边框亮一级，在卡片内顶部。它的作用是暗示「这里有光照」——毛玻璃的核心是光线感。

### 5.5 组件规范

#### 按钮（界面的灵魂）

按钮是新粗野主义的门面。它的硬偏移阴影是整个界面最有辨识度的元素。

**主按钮：**
```
背景:      #7c3aed
描边:      2px #5b21b6（深紫）
文字:      #e0e0e0, 15px Semibold, letter-spacing 4px
高度:      44px
阴影:      4px 底部硬偏移 #000（无模糊）
圆角:      0（硬边）

Hover:    阴影拉到 6px → 按钮视觉上「浮起来」
Active:   阴影缩到 2px → 按钮视觉上「按下去」
Disabled: 文字变灰 #666666，阴影消失
```

**次按钮：**
```
背景:      transparent
描边:      2px #7c3aed
文字:      #7c3aed, 15px Semibold, letter-spacing 4px
阴影:      同主按钮
```

> 按钮文字加 letter-spacing 是排版设计的基本手法——拉开字距让文字看起来更像「标题」而不是「段落」。按钮文字本身就是一种微型标题。

#### 输入框

```
背景:      #0a0a0a（和窗口背景同色，在卡片内形成凹陷感）
描边:      1px #222222
文字:      #e0e0e0, 14px
Placeholder: #444444（比次文字色更暗，不参与视觉竞争）
高度:      40px
圆角:      0

Focus:    描边变 #7c3aed, 2px
```

输入框用 `#0a0a0a`（和窗口背景同色）而不是更浅的色——这创造了一种「挖洞」的效果：卡片表面被挖开，露出底层的深色。这种凹陷感比画一个浅色边框更有空间感。

#### 密码显示切换

不是独立的按钮。是输入框右侧内嵌的一个文字标签「显示 / 隐藏」，颜色 `#666666`，点击时不改变大小和位置，只切换文字和密码显示状态。它是输入框的一部分，不是一个独立的控件。

#### 下拉选择框

和输入框同样式，右侧有一个 `▾` 符号。下拉展开的选项列表背景 `#141414`，hover 项背景 `#222222`，文字 `#e0e0e0`。

#### Tab 切换

两个文字按钮并排，没有背景框。
- 激活 Tab：`#7c3aed`，下方 3px 紫色指示线
- 非激活 Tab：`#666666`，无指示线
- 切换时瞬切，无过渡动画

#### 开关（Switch）

设置面板用的开关：
- 关闭态：灰色轨道 `#222222`，灰色圆点 `#444444`
- 开启态：紫色轨道 `#7c3aed`，白色圆点 `#e0e0e0`
- 没有文字标签在开关旁边——标签在左侧，开关在右侧，中间用空间分隔

#### 状态指示

```
● 已连接      ← 紫色圆点 #7c3aed + 11px 灰色文字 #666666
● 断网        ← 灰色圆点 #444444 + 11px 灰色文字 #666666
● 登录中…     ← 紫色圆点 #7c3aed + 11px 灰色文字 #666666
● 未配置      ← 灰色圆点 #444444 + 11px 灰色文字 #666666
```

只有两个色阶：紫（好）和灰（不好/默认）。不用红色表示错误，不用绿色表示成功。紫色 = 有信号，灰色 = 无信号。简单到不需要解释。

### 5.6 毛玻璃效果的实现

customtkinter 不支持 backdrop-blur，所以我们用**视觉模拟**。毛玻璃的本质不是模糊，是**层次感**。

三要素：
1. **色差**：背景 `#0a0a0a` → 卡片 `#141414`，两级灰度差制造「表面浮在背景上方」的感觉
2. **高光线**：卡片内顶部 1px `#2a2a2a`——像玻璃边缘折射的微光。没有这条线，卡片就是一块死板的灰色
3. **边缘线**：2px `#222222` 边框——定义玻璃的边界，让它感觉是一个「片」而不是「块」

这三层叠加在一起：一个深底，上面浮着一片略亮的玻璃，玻璃边缘有光。这就是毛玻璃。

---

### 5.7 动效系统

动效的唯一目的是**让交互有触感**。不是装饰，不是炫技。

customtkinter 无原生动画，全部 `after()` 手写。只做三件事：

| 场景 | 效果 | 时长 | 目的 |
|------|------|------|------|
| 按钮 hover | 底部阴影 4→6px | 0ms 瞬变 | 手感：按钮浮起来了 |
| 按钮 active | 底部阴影 4→2px | 0ms 瞬变 | 手感：按下去了 |
| 登录结果 | 按钮文字临时变 ✓ / ✕ | 1500ms 恢复 | 反馈：操作有结果了 |
| 输入框 focus | 描边变紫 | 0ms 瞬变 | 定位：告诉用户焦点在哪 |

**所有动效都是瞬变（0ms），没有渐变过渡。** 粗野主义不搞渐变。状态变了就是变了，干净利落。

**绝对不做的：** Loading 转圈、呼吸灯、淡入淡出、弹跳、Tab 滑动、窗口开关动画、任何持续时间超过 100ms 的动效。

---

### 5.8 设计红线（绝对不做）

```
❌ 圆角——所有元素必须是直角，0px radius
❌ 纯白 #ffffff 文字——用 #e0e0e0
❌ 渐变——任何地方都不允许
❌ 软阴影——阴影必须是硬偏移，0 模糊
❌ 发光效果 / glow / neon
❌ 居中布局——所有内容左对齐
❌ Emoji 做 icon
❌ AI 套话文案（「欢迎使用」「开始您的旅程」）
❌ 大面积紫色——紫色只做点缀，面积永远 < 5%
❌ 等间距排列——间距必须有节奏，有紧有松
```
